# Future Integration Points

The widget currently runs on mock data only.

Prepared connection options:

- `statusApiUrl`: read focus state and task data from a local `/status` API.
- `statusJsonPath`: read the same shape from a JSON file generated by the focus engine.

The widget polls `http://localhost:5000/status` once per second. If the API is unavailable, it falls back to `src/data/mockFocusState.json`.

Expected `/status` response shape:

```json
{
  "state": "focused",
  "current_app": "chrome.exe",
  "current_url": "https://example.com",
  "activity": "typing",
  "idle_time": 0,
  "window_switch": 2,
  "elapsed_time": 185
}
```

Expected focus states:

- `focused`
- `warning`
- `distracted`
- `idle`

Existing Python focus tracker and Chrome extension files are intentionally not imported or modified.
